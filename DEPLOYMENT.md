### Auto-Deployment
Every push to `main` branch automatically:
1. Triggers GitHub Actions workflow
2. Builds and deploys to GitHub Pages
3. Updates the live PWA instantly

## 🎆 Features
- **4 Color Themes:** Classic, Neon, Green/Cyan, Gold
- **Intensity Controls:** 20-200 particles per burst
- **Sound Effects:** Procedural boom sounds
- **Keyboard Controls:**
  - Arrow Keys: Change theme & intensity
  - M: Toggle sound
  - H: Toggle help overlay
  - F: Fullscreen
  - Click: Launch firework at cursor
